# Ingolstadt Hbf — интерактивный диспетчерский replay

Приложение читает **существующие CSV из AnyLogic**. Никаких правок в `Ingo.alp`, event log, AnyLogic API или дополнительных лицензий не требуется. Streamlit работает **локально в браузере**.

## Установка

1. Скопируй из архива папку `analysis/` в корень репозитория `IngoHbfSimulation` (если папка `analysis` уже существует, просто добавь файлы, не удаляя `analyze_results.py`).
2. Открой терминал в корне репозитория.
3. Установи зависимости:

   ```bash
   python -m pip install -r analysis/requirements_dashboard.txt
   ```
4. Запусти dashboard:

   ```bash
   python -m streamlit run analysis/station_dashboard.py
   ```

Обычно откроется `http://localhost:8501`. Если не открылось автоматически, скопируй адрес из терминала в браузер.

## Возможности

- Выбери сценарий (`S002`, ... `S101`) и стратегию или сравнение обеих.
- Используй ползунок времени, кнопки `+/- 1 мин` или `▶/⏸` для автоматической прокрутки.
- Видишь в каждый момент: свободные и занятые Gleis 2–5, текущие очереди с севера/юга, поезд, запланированную и фактическую платформу, время ожидания.
- Ниже — сравнительные KPI за весь сценарий, Gantt по занятости платформ, динамика очередей и подробная таблица поездов.
- CSV можно экспортировать из таблицы прямо в интерфейсе.

**Важное ограничение:** это не живая связь с работающим экспериментом AnyLogic. Временное состояние восстанавливается из результатов уже завершённого прогона. Именно это делает решение независимым от AnyLogic PLE. Схема путей схематичная, без реальных стрелок и конфликтов маршрутов.

## Если файлов не видно

Укажи правильный абсолютный путь к `Ingo/results` в левой панели. Нужны как минимум два файла **одного сценария и seed**:

```text
train_results_FIXED_DB_S002_seed102.csv
train_results_GREEDY_S002_seed102.csv
```

Нажми **«Обновить CSV»**, если новые результаты появились после открытия страницы. В CSV должны быть все колонки существующего формата (`planned_platform`, `assigned_platform`, `ready_time`, `platform_arrival`, `actual_departure` и др.).

## Для презентации

Открой режим **«Обе стратегии»**, выбери `S002` и поставь время 20–80 минут. Затем нажми ▶, чтобы увидеть как меняются очереди и занятость платформ. На диаграмме Gantt можно навести мышь на любой поезд и увидеть план/факт платформы и задержку.
